# 🏟️ Sports Broadcast Sponsorship Dashboard

An interactive, single-page dashboard that analyses how much on-screen exposure sponsor brands receive during Australian sports broadcasts, and how fans feel about them.

## Overview
The dashboard tracks brand exposure events across 60 matches (Aug 2025 – Feb 2026) in five leagues (AFL, NRL, A-League, BBL and Super Rugby), broadcast on Channel 7, Channel 9, Fox Sports and Kayo. It covers 8 sponsor brands, including CommBank, Telstra, Optus, Qantas, Toyota, Coca-Cola, Adidas and XXXX Gold, across 1,456 exposure records.

## Features
- **League and brand filters** that update every chart and KPI instantly
- **KPI strip:** total exposure seconds, matches analysed, average audience (millions) and average fan sentiment (out of 5)
- **Six charts:**
  - Total exposure by brand
  - Average exposure by camera angle (close-up, wide shot, replay, aerial/drone, player cam)
  - Weekly exposure trend
  - Audience size vs. match exposure (scatter, coloured by league)
  - Average fan sentiment by brand
  - Average exposure by placement type (LED perimeter, stadium signage, jersey, broadcast overlay)
- Responsive layout for desktop and mobile


## How to Run
Download `Sports_Sponsorship_Dashboard.html` and open it in any modern browser.

## Note
All data is simulated for portfolio and demonstration purposes.
